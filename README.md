# Stride

A focused personal training app.

Only public application assets are stored in this repository. Workout records, measurements and coach reports require the authorized Google sign-in and live in a separate private database.

Open https://ahmedk-max.github.io/stride/ in Safari and choose Share → Add to Home Screen.

Third-party dataset, anatomy, icon and benchmark attribution is included with the app. Remote exercise media remains subject to its original provider terms.
